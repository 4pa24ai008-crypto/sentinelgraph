# SIH Demo Flow

1. Open the website — the main dashboard appears directly.
2. Start with the hero description: explain the fragmented-data problem and the goal of uncovering hidden relationships.
3. Show the four metrics.
4. Open Network Graph and click a person/entity.
5. Open Person Search and show direct connections.
6. Run AI Analysis and explain why the signal is flagged.
7. Open Risk & Alerts and show prioritized evidence.
8. Upload the provided CSV template or a project dataset.
9. Show Location Analysis.
10. If required, start the backend and show SQLite/API status.

Recommended presentation line:
"SentinelGraph converts fragmented crime intelligence into an explainable relationship network, helping investigators discover hidden connections, prioritize suspicious patterns, and trace the evidence behind each signal."
